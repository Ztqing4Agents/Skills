# 写契约

「现在必须成立的事实」住在哪、长什么样、什么时候必须改。**参考类见 [writing-reference.md](writing-reference.md)，`archive/` 见 [layout.md](layout.md)。**

## 类型取值与头注（唯一对照表）

`类型:` 只有三个取值，决定了「要补哪些头注键、有哪些必填章节、能用多大」。门禁 G2/G3/G4 全部按这张表判——**别处不再定义类型语义**。

| `类型:` | 头注必填键 | 必填章节 | 档位 | 典型文件 |
|---|---|---|---|---|
| 契约 | 五键 | `## 范围`、`## 条款`、`## 验收` | 契约档 | `spec.md`、`docs/contracts/api.md` |
| 参考 | 七键（五键 + `采集日期:` + `来源版本:`） | 不强制 | 参考档 | `reference.md`、`docs/reference/api-2024-04.md` |
| 规范 | 五键 | 至少一个含「验收」的 `##` | 规范档 | 团队编码规范、发布流程 |

档位数值见 [layout.md](layout.md) 的「档位与行数线」；`README.md` / `AGENTS.md` / `CHANGELOG.md` 豁免头注，各有固定形状（见对应细则）。

```markdown
> 类型：契约
> 读者：<谁，在什么时刻读>
> 真源：<代码 / 测试在哪个文件，或哪条命令能验证>
> 更新触发：<什么改动必须同步改这里>
> 规模上限：<按类型档位填数字>
```

模板：[assets/spec.template.md](../assets/spec.template.md)；参考类用 [assets/reference.template.md](../assets/reference.template.md)。

**冒号体例**：键名在正文里写成 `` `类型:` ``（半角，当标识符用），写进文件的头注行是 `> 类型：…`（全角，当文字用）。门禁两种都认，不要在同一处混。

## 章节：顺序自由，存在性必填

必填章节已在上面那张类型表里定死（契约三节、规范一个「验收」、参考不强制）。这里只补两条判断：

- **章节名固定，是为了让 agent 能 grep 定位**，不必读全文；**顺序不固定**，避免「这一节该放第几」的无意义论证。
- **`## 术语` / `## 决策` 是可选的**：有歧义的词才进术语表，有被否掉的方案才写决策。

**`类型：规范` 是唯一的形状例外**：它的章节是领域编号（`## 1 五条原则` … `## 12 判据与已知陷阱`），硬套三节模板会要求重排一份已经成型的真文档。它只强制一件事——**必须有一个含「验收」的章节**，因为那是唯一有行动价值的部分。

## 条目形态：一句断言 + 锚点 + 失效触发器

- ✗ 「结构应保持简洁」——不可证伪，十年后还在，且没人能执行
- ✓ 「`.hid_previewGlyph` 恒占 28px（锚点：`PAGE_CSS` 的 `--hid-slot`）；宿主改槽宽即失效」

**锚点必须是能在代码里 grep 到的东西**（符号名 / 选择器 / 常量）。写「大约 28px 左右」等于没锚点。

**指路坐标默认写裸 `§x.y` / `附录 X.n`**（编号全仓唯一是前置条件），不要一边叫「锚点」一边指两样东西。只有可能歧义时才补文件名——路径限定越多，将来拆分文档时要改的引用越多。

## 三条边界

- **`## 条款` 里不写「为什么」**——理由进 `## 决策` 或 commit message。混在一起没人能一眼找到规矩。
- **不写没主体的将来时**——要么带看板 ID，要么删（见 [SKILL.md](../SKILL.md) 的「七条铁律」第 7 条）。
- **`## 验收` 每条都必须是命令或可观察现象**。「应当保持一致」等于没写。

## 改稿五问（任一卡住就不写）

1. **这句话让文档里哪句变假了？** 有 → 改那句，不许新增；没有 → 才追加。
2. **它点名的符号 / 数字现在还在吗、还对吗？** 不在 → 删或改，**不许补写「以前是」**。
3. **这层保证还有别处承担吗**（测试 / lint / 类型）？有 → 删，别抄第二遍。
4. **删了它谁会做错事？** 说不出人 → 删；说得出 → 留下并写清失效触发器。
5. **这句话描述的是旧行为还是新行为？** 两处真相并存、又不标哪个是现行，读者只能猜——这比「诚实地说已经过时」更糟。

**追加合法的唯一条件**：新条目有自己的锚点或触发器。同一小节连续只增不减，就是腐化信号——见 [doc-rot-signals.md](doc-rot-signals.md) 的最后一条。
